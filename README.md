# CardioVisua App

CardioVisua is a cardiac visualization and prediction application powered by artificial intelligence. It enables users to analyze medical data, display a 3D model of the heart, and generate predictions using trained models.

---

## 🩺 Project Objective

The goal of **CardioVisua** is to support the understanding and visualization of cardiac signals through predictive models and 3D representations.

The application highlights the integration of **medical AI** and **interactive visualization**.

---

## 🚫 Excluded Data and Models

The `data/` directory is **not included in the GitHub repository** for two main reasons:

1. **File size:** 3D models and prediction data can be large.
2. **Licensing restrictions:** Certain medical datasets and models cannot be publicly redistributed.

---

## 📂 Data and Contents of the `data/` Directory

The `data/` directory is **not included in the public repository** due to licensing restrictions and file size.

It contains the data and files required to run the application locally:

- `ECG/`: Sample ECG signals from the **MIT-BIH Arrhythmia Database**, used to demonstrate the 1D CNN model.
- `prediction/`: Prediction outputs generated by the models, including segmented MRI scans, masks, and related files.
- `testing/`: A subset of MRI scans from the **ACDC (Automated Cardiac Diagnosis Challenge)** dataset.
- `heart.obj`: A 3D heart model used for interactive visualization.

> ⚠️ The **ACDC** and **MIT-BIH Arrhythmia** datasets are subject to specific usage licenses and cannot be publicly redistributed through this repository.
>
> 🔗 Official sources:
>
> - **ACDC Dataset:** https://www.creatis.insa-lyon.fr/Challenge/acdc
> - **MIT-BIH Arrhythmia Database:** https://physionet.org/content/mitdb/1.0.0/

Users who wish to reproduce the results must **download these datasets themselves** from the official sources and place the files in the `data/` directory according to the structure described above, subject to the applicable licenses.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/02-kuro/CardioVisuaApp.git
cd CardioVisuaApp
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Add the Required Data Files

Create a `data/` directory in the project root and place the required 3D model files and prediction models inside it, provided their licenses permit their use and distribution.

Ensure that the files follow the directory structure described in the **Data and Contents of the `data/` Directory** section.

### 4. Run the Application

```bash
python app.py
```
